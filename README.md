# Автогонки

Клиент-серверная симуляция кольцевой клеточной автотрассы. Сервер хранит единственное авторитетное состояние гонки и рассылает события по TCP; клиент подключается как независимый наблюдатель. Сервер обслуживает до 128 одновременно подключенных клиентов и позволяет наблюдателю присоединиться или отключиться во время гонки.

## Сборка и проверки

```sh
make
make test
```

Для очистки результатов сборки выполните `make clean`.

## Запуск

Сервер принимает TCP-соединения на всех интерфейсах, ожидает подключения наблюдателей и запускается командой `start`:

```sh
./build/race-server --bind 0.0.0.0 --port 5000 \
  --config tests/data/short-race.conf --delay-ms 100
```

В другом терминале запустите одного или нескольких наблюдателей:

```sh
./build/race-observer --host 127.0.0.1 --port 5000 --name desk-1
./build/race-observer --host 127.0.0.1 --port 5000 --name desk-2
```

После подключения клиентов в терминале сервера введите `start`. Команда `status` показывает состояние и подключенных наблюдателей; `quit`, `SIGINT` и `SIGTERM` завершают сервер с уведомлением подключенных клиентов. Если сервер и клиент работают на разных компьютерах, вместо `127.0.0.1` укажите адрес сервера и обеспечьте доступ к TCP-порту.

Для автономного запуска с завершением сервера после гонки:

```sh
./build/race-server --bind 127.0.0.1 --port 5000 \
  --config tests/data/short-race.conf --delay-ms 80 --autostart --once
```

## Конфигурация

Конфигурационный файл содержит пары `ключ=значение`: `lanes`, `cells`, `laps`, `teams`, `bonus_points`, `retire_gap`, `max_rounds`, `classification`, `seed`. Значение `retire_gap=0` отключает снятие отставших машин; положительное значение снимает в конце раунда активную машину, отставшую от лидера на указанное число клеток. `classification=finish` ранжирует финишировавшие машины по времени финиша, а сошедшие — по дистанции; `classification=points` сначала сравнивает круговые бонусные очки. `#` в начале строки вводит комментарий конфигурации.

Адрес, порт и настройки запуска задаются параметрами сервера `--bind`, `--port`, `--seed`, `--delay-ms`, `--retire-gap`, `--max-rounds`, `--autostart` и `--once`. Остальные параметры задаются в файле. Клиенту доступны `--host`, `--port`, `--name`.

Дополнительное описание архитектуры, протокола, правил модели и результатов приведено в [`report.md`](report.md).
